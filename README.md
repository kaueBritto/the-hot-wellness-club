# The Hot Wellness Club

Demonstração de design do site do The Hot Wellness Club (hot pilates em Aracaju).

- É um site estático de apresentação: a reserva e os botões de contato são simulados e não gravam nada.
- As vagas da grade de horários são exemplos.
- Textos, valores e regras vêm do site atual do estúdio.

Publicado com GitHub Pages: https://kauebritto.github.io/the-hot-wellness-club/
